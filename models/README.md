\# Medical Diagnosis Models



The trained deep learning models used by this project are not stored directly in this GitHub repository because of their large file sizes.



The application uses seven different medical diagnosis models.



\## Models



| # | Disease / Diagnosis | Model File |

|---|---------------------|------------|

| 1 | Brain Tumor MRI | brain\_tumor\_model.h5 |

| 2 | COVID-19 X-Ray | CNN\_Covid19\_Xray\_Version.h5 |

| 3 | Diabetic Retinopathy | Diabetic-Retinopathy-ResNet50-model.h5 |

| 4 | Malaria | malaria.h5 |

| 5 | Lung Cancer Detection | lung\_cancer\_detection\_model.h5 |

| 6 | Lung Cancer Histopathology | lung-cancer-resnet-model.h5 |

| 7 | Retinal OCT | Retinal-OCT-resnet-model.h5 |
