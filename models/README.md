# Medical Diagnosis Models

The trained deep learning models used by this project are not stored
directly in this GitHub repository because of their large file sizes.

The application downloads the models from the project's public Kaggle dataset.

Kaggle Dataset:

https://www.kaggle.com/datasets/abdelghafarseddiki/federated-medical-diagnosis-models

Models included:

1. Brain Tumor MRI
2. COVID-19 X-Ray
3. Diabetic Retinopathy
4. Lung Cancer X-Ray
5. Lung Cancer Histopathology
6. Malaria
7. Retinal OCT

The models are downloaded automatically when required by the application.
